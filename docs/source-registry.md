## Evidence rule

When a third-party project, article or tool points to potentially valuable public data, investigate and validate the original upstream source. Only the upstream source is recorded here unless the external project itself contributes something genuinely unique that we explicitly adopt.

Detailed source contracts are added as each source is investigated and its operational role is finalized.
